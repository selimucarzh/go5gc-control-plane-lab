What This Shows

The current repository implements the minimum useful control-plane split.

Registration

AMF accepts SUPI, PLMN, and access type, then stores a UE context in memory.

Verification

SMF asks AMF for the UE context before creating any PDU session.

Session State

SMF stores session context by SUPI and session ID, returning an existing session when repeated.

Kubernetes Step

The same AMF and SMF binaries can be built into local images and deployed with deploy/k8s.
